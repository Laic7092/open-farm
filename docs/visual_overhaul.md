# 视觉升级：3/4 斜俯视路线

> 本文回答「现在的画面为什么平、分几刀把它改成 3/4 斜俯视、哪些方案已经否决」。
> 具体坐标 / 颜色 / 字段以 `tools/art/*.gd` 的 `##` 注释、`src/art/palette.gd`
> 与 `docs/art_pipeline.md` 为准；本文只做路线与取舍的记录。

## 1. 诊断：世界是 3/4，素材却是「立面」

游戏世界（TileMap + Y 排序 + 方向光）已经是斜俯视的，但大量素材是**正面立面**：

| 症状 | 证据 | 体感 |
| --- | --- | --- |
| 建筑只有一个正面 | `house.png` / `barn.png` 的屋顶是左右对称的三角，没有侧面 | 房子像舞台布景，转身就穿帮 |
| 树冠是正圆色块 | 高光居中、暗部均匀 | 树像一个贴纸，没有体积 |
| 栅栏 / 崖壁是平涂块 | `_fence` / `_cliff` 只有正面纹理 | 地面边界没有「立起来」 |
| 前后关系被整张图绑死 | 玩家与整棵树 / 整栋房做 Y 排序 | 站在建筑前头会被屋檐盖住，站到建筑后又整个人被挡没 |

结论：缺的不是分辨率或配色，而是**体积感**和**分层关系**。

## 2. 路线：3/4 斜俯视 + 前景分层

**已拍板**：继续全脚本生成，不走手绘位图；整体维持 16 像素网格与明度分层调色板。

两个正交目标：

1. **每个大件都要有第二个体面**：房子看到正面 + 右侧面，树冠看到受光顶面与背光下缘，
   栅栏看到柱顶，崖壁看到上缘。统一光照方向：**左上受光、右下投影**。
2. **可通行区域不能被整张图挡住**，但遮挡关系要分两种：
   - **树冠**这类天然压在头顶的窄件拆成独立 overlay，始终画在角色之上；
   - **建筑 / 柜台**这类大实心件走「身后淡出」：保留正常 Y 排序，人躲到北侧被挡住时
     整张图降到 ~42% 不透明度。第一版曾给所有屋檐都做了 overlay，实测出现
     「身体在前、头被屋檐盖住」的割裂感，已按后者修正。

### 已否决

- **手绘替换 PNG**：违背「仓库不放手工二进制素材」的规范，也不可复现。
- **给整张素材加描边 / 投影冒充体积**：只增加脏点，不解决面数。
- **旋转整张建筑贴图做 3/4**：像素会糊、落地线会偏，碰撞盒对不上。
- **第二套图集 / 第二套 source**：图集排版是单一事实来源，禁止分叉。
- **把 overlay 画进同一张图靠 z_index**：整图 Y 排序时局部压不住人，必须真的拆。

## 4. 本轮执行记录

### 4.1 3/4 立面重画

- **农舍 / 谷仓**（`tools/art/generate_props.gd`）
  - 右侧山墙向后上方退 9×6，出现真正的侧面。
  - 山墙三角 + 两坡屋顶（左坡受光、右坡背光），屋脊从前向后收。
  - 瓦垄与檐口斜边独立成线，烟囱坐在坡面上。
- **树 / 松树**（同文件）
  - 树冠改为「右下暗底 → 中间色 → 左上高光 → 下缘再压暗」，果实在受光侧。
  - 树干增加根盘；松树改三层三角，每层左亮右暗。
- **栅栏 / 崖壁**（`tools/art/generate_terrain.gd`）
  - 栅栏：一前一后两根柱子、柱顶高光、两道横杆带顶面与底面、柱脚投影。
  - 崖壁：顶部亮边 + 檐口阴影 + 竖向层理，底部收暗，读起来像凹进洞壁。

### 4.2 遮挡分层：树冠 overlay + 建筑身后淡出

两种机制由 [WorldProp] 按碰撞盒宽度自动分流，**无需改任何场景坐标**：

| 类型 | 判定 | 行为 | 适用 |
| --- | --- | --- | --- |
| 前景 overlay | `solid_size.x < 40` 且同目录有 `fg_<名字>.png` | 建一个绝对 `z_index = 1` 的子 `Sprite2D`，最后再画一遍悬空部分 | 树 / 松树（`fg_tree` / `fg_tree_pine`） |
| 身后淡出 | `solid_size.x >= 40` | `_process` 里判断玩家是否在自己纵向投影内且在北侧（身后），是则 `modulate.a → 0.42`，离开恢复 | 房子 / 谷仓 / NPC 住宅 / 柜台 / 洞口 |

**overlay 约定**：`<名字>.png` 的 overlay 叫 `fg_<名字>.png`，同目录、同尺寸、同锚点；
底图保持完整，因此碰撞盒与 `LightOccluder2D` 仍按完整剪影提取，剪影测试也不受影响。
树冠 overlay 由 `_tree_overlay()` 单独绘制（不含树干）。

**淡出约定**：保留正常 Y 排序，只在玩家落到建筑北侧、真的会被贴图挡住时变半透明；
方向光遮挡（`LightOccluder2D`）仍按完整建筑计算，所以地面阴影不会跟着淡。
`fade_when_behind=false` 可以关掉某个摆件的淡出；`behind_alpha` / `fade_speed`
控制淡出深度与速度。
