# open-farm 玩法指南

本文面向玩家，说明核心循环与当前可玩内容；按键见 [README 操作表](../README.md#操作)。
数值、具体道具与规则以 `data/**/*.tres` 和代码为准。

## 标题页

启动后先进入标题页：脚本生成的日出农场背景与飘动的云。
菜单有新游戏、继续游戏、切换中英文、退出；方向键或 `W S` 选择，`Enter` 确认。
没有存档时“继续游戏”按钮整个隐藏，焦点直接落在“新游戏”上；有存档时下方显示最近一局的摘要。
点“继续游戏”会打开存档列表：每一项显示序号、日期与金钱，`Enter` 读取，`Delete` 删除，`Esc` 返回。
存档槽位没有数量上限，想开几局就开几局。

## 开局：第一天可以做什么

出生在自家农舍门口；床和出货箱就在门口两侧，往南是农田区（带栅栏那片），沿乡道往东出农场就是村庄。

- 用锄头翻地 → 浇水 → 用 `seed_bag`（初始物品栏第 4 格）播种 → 成熟后按 `E` 徒手收获。
- 收获物可放进农舍门口的出货箱一键卖出。
- 农舍右边是鸡舍，右上是牛舍；去 `twon` 的杂货店买鸡 / 奶牛与干草。
- 回农场对着畜舍按 `E` 放养牲畜，对着饲料槽按 `E` 一次性喂饱全舍。
- 喂养足够天数后成年，之后每隔几天产出鸡蛋 / 牛奶；对着牲畜按 `E` 收走，每天第一次按 `E` 还能抚摸提升好感。

## 每日节奏

- 起床后先处理农田与畜舍，再去镇上买卖、社交或推进事件。
- 体力耗尽前记得吃饭 / 回家睡觉；睡觉会推进到第二天。
- 日结转会结算天气、作物生长、牲畜成长、NPC 日程、节日与一次性事件；结算结束后自动存档到本局槽位。
- `Esc` 打开菜单可保存 / 读取本局进度，也可回到标题页；快捷存读档为 `F5` / `F9`。

## 地图与 NPC

当前地图链：
`农场 farm` → `村庄 twon` → `集市 town` → `海滩 beach` → `矿洞 mine`；
`twon` 另有一条岔路通往 `图书馆 library`。

- 地图两侧出口压在地图纵向中线上，`SceneDoor.auto_enter` 为真：走到边缘即换图，落脚点与对面道路同高。
- 8 位 NPC 有各自日程：白天按时刻表前往商店 / 镇公所 / 铁匠铺 / 花摊 / 广场等地。
- 商店改由柜台负责：老板上班且站到柜台后面时，对着柜台按 `E` 才会开店；直接和老板交谈只是聊天。
- 渔夫、矿工、图书管理员分别住在海滩、矿洞、图书馆。

## 钓鱼

整条流程分三段：**蓄力抛竿 → 等鱼 → 拉扯收杆**。

- 钓竿开局就在背包里（物品栏第 7 格，用 `Q` / `R` 切到它）。
- **抛竿**：站到水边、面朝水面，**按住** `空格` 蓄力（HUD 上方出现蓄力条），松手抛出。蓄得越满甩得越远，
  也越容易碰上难钓的鱼；轻点一下也能抛，只是落点贴岸、多半只有常见鱼。
- **等鱼**：浮标入水后会上下漂浮，几秒内有鱼咬钩（浮标下沉 + 提示音）。等鱼时按一下 `空格` 可提前收竿。
- **拉扯**：咬钩后进入拉扯小游戏——屏幕右侧出现一条竖直“水槽”，蓝鱼是它、红白浮标是你的钩子。
  **按住** `空格` 收线上浮、松开让钩子下沉，把钩子压在鱼身上：压住时“上钩”进度上涨、“张力”回落，
  脱开则进度回退、张力飙升。进度满 = 上岸，进度归零或张力拉满 = 断线跑鱼。
  鱼旁边的浅色带是判定区，越难的鱼判定区越窄、游得越快；升级钓竿会放宽判定区。
- 每抛一竿消耗 1 点体力（无论最后钓没钓上来）。
- 竿尖到浮标之间有一根看得见的鱼线：抛竿时跟着浮标飞出去，等鱼时松弛下垂，扯扯时随张力绷直并抖动，收杆时缩回竿尖。
- 水域分两种：**海**在集市东边的海滩（地图下方的开阔水面与栈桥附近），**池塘**在村庄与集市里。
- 能钓到什么取决于水域、季节、天气与时刻：
  - 海里白天常见沙丁鱼、鲭鱼，春夏有鲷鱼，夏秋夜里能碰上鱿鱼，盛夏白天才有机会钓到章鱼与金枪鱼。
  - 池塘里鲫鱼、鲤鱼常驻，雨天才有鲶鱼，金鲤常年有但极稀有。
- 鱼可以放进出货箱卖钱，也是渔夫喜欢的礼物。

## 好感度与恋爱

- 每天第一次交谈、送对礼物会提升好感；50 点好感 = 1 颗心。
- 铁匠、花婆婆、渔夫、书雅可以攻略。
- 4 心触发表白；5 心并携带蓝色羽毛（杂货店有售）再次交谈即可求婚。
- 婚后满 10 天会迎来孩子，孩子出生后会出现在农舍旁。

## 节日与事件

- 日历上的节日：
  - 春 1：新年祭
  - 春 14：花祭
  - 夏 24：烟花大会
  - 秋 15：收获祭
  - 冬 25：星夜祭
- 节日当天 NPC 会放下日程去会场集合，HUD 顶部显示“今日节日”；到场按 `E` 参加，可给每位到场 NPC 加好感（每年一次）。
- 首次参加节日通常还有一段开场对白。
- 一次性事件（旅人来访、夏季补助、初雪等）在日结转时按条件判定，命中后结算并弹出提示。

## 存档

- 每个存档槽就是“一局游戏”，槽位没有数量上限；新游戏在第一次保存（手动或日结自动）时分配一个空槽位。
- 手动存档收敛成“保存当前这一局”：系统菜单的“保存进度”与 `F5` 都写到本局槽位，不再手选槽位。
- 每天日结结束后自动存档一次；菜单的“读取进度”与 `F9` 会重载本局。
- 想换一局或新开一局请回到标题页：新游戏开新档，“继续游戏”在存档列表里选一局。
