# open-farm · 牧场物语复刻

用 **Godot 4.7.2** 制作的 2D 俯视角像素农场生活模拟：农场 / 畜牧 / 钓鱼、NPC 与好感度恋爱、节日与事件、
多张地图、UI、存档与本地化均已打通。**美术、字体、BGM、音效全部由脚本生成**，仓库不放手工二进制素材。

## 快速开始

```bash
./godot --path .                        # 运行游戏
./godot --path . -e                     # 用编辑器打开
timeout 800 ./tools/check.sh            # 大文件体检 + 单元测试 + 冒烟测试（提交前必跑）
timeout 800 ./tools/check.sh unit       # 只跑单元测试
timeout 800 ./tools/check.sh smoke      # 只跑冒烟测试
timeout 800 ./tools/build_assets.sh     # 重新生成全部 PNG / 字体 / WAV
```

`GODOT_BIN=/path/to/godot` 指定引擎，`GODOT_TIMEOUT=120` 覆盖默认 60s 命令超时。

审阅游戏内容（不启动游戏）：`./tools/build_wiki.sh --open` 把 `data/**/*.tres` 与文案渲染成
静态 HTML（`.tmp/wiki/index.html`），含各系统卡片、对白分支、商店货架、文案对照与图片墙；
`--strict` 可在有缺译 / 悬空引用时非零退出。

线上站点（GitHub Pages，一次发布整站）：`/wiki/` 内容 wiki、`/game/` Web 试玩，根路径是导航页。
push main 命中构建路径（`src/**`、`scenes/**`、`assets/**`、`data/**` 等）时全量重建两者，
也可在 Actions 里手动 Run，或推 `v*` tag。
本地导出 Web：`./tools/build_web.sh`（需先装同版本 export templates），产物在 `target/web/`。

## 操作

键鼠：纯键盘，鼠标隐藏；菜单 / 商店 / 标题页可用方向键或 `WASD` 导航，`E` / 空格 / `回车` 确认，`Esc` 返回。
触控：系统菜单里的「虚拟摇杆」打开后，左下角出现摇杆，右下角出现 ABXY 四个动作键——
世界里 `A` 主操作、`B` 菜单、`X` 换具、`Y` 背包；模态界面里只保留 `A` 确认、`B` 返回。
摇杆推到底即奔跑，不用按 `Shift`（键位提示也写在系统菜单里）。
有触摸屏的机器（手机 / 平板）默认就是打开的；开关存在 `user://display_settings.cfg`，与存档无关。

| 按键 | 功能 |
| --- | --- |
| `W A S D` / 方向键 | 移动；按住 `Shift` 奔跑 |
| `E` / `空格` / `回车` | 主操作：收获 / 对话 / 交互 / 使用当前工具；水边手持钓竿时按住蓄力抛竿，咬钩后按住收线 |
| `Q` | 切换手持物品（单向循环） |
| `Tab` | 背包（再按关闭；`Esc` 也可关闭） |
| `Esc` | 系统菜单 / 关闭当前界面（商店内 `A` / `D` 切换买卖列表） |

背包里有 NPC 喜欢 / 讨厌列表里的礼物且今天还没送过时，对 NPC 按主操作键会优先送礼；
当天送完后，同一个按键继续正常对话。

## 怎么玩

出生在农舍门口，核心循环：翻地 → 浇水 → 播种 → 收获 → 出货箱换钱 → 买种子 / 牲畜 / 升级；
`E` 睡觉推进日结（结算天气 / 成长 / NPC 日程 / 节日，并自动存档）。

每个系统的细节不在这里复述：数值与规则看 `data/**/*.tres`，装不下的推 `##` 注释。
